📚 Fächer Quiz









➕ Eigenes Fach erstellen




📤 Fach exportieren

Du kannst dein ausgewähltes Fach als JSON-Datei speichern und an einen Freund schicken.

📥 Fach importieren

Wähle eine JSON-Datei aus, die dir jemand geschickt hat.


💡 So funktioniert es:

1. Du erstellst ein eigenes Fach.
2. Du speicherst es.
3. Du klickst auf „Als JSON speichern“.
4. Die JSON-Datei schickst du deinem Freund.
5. Dein Freund öffnet seine Webseite.
6. Er wählt die JSON-Datei aus.
7. Er klickt auf „JSON-Fach importieren“.
8. Das Fach erscheint in seiner Fächerliste. 🎉
